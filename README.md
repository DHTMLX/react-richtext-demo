## How to start

### Online

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/DHTMLX/react-richtext-demo)

### On the local host

Clone the repository or download files.

```
yarn
yarn start
```

or

```
npm install
npm run start
```
